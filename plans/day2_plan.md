## 09:00 — 큐가 움직였는지 먼저 확인 (5분)

→ **학습 잡이 실제로 시작되지 않는 상태**로 의심된다.

1. `Your models` 목록을 열어 Status를 본다.
2. `Ready`가 하나라도 있으면 → 정상. 다음 단계로.
3. 전부 `Queued`라면 → 안 쓰는 모델을 지워 앞자리를 비운다:
   `stable-antigravity`, `fight-antigravity`, `TEST1` 2개 → Actions → Delete
4. 그래도 안 움직이면 **운영진에게 문의**:
   - "학습 잡이 Queued에서 진행되지 않는다"
   - **"동시 학습 몇 개까지 가능한가"** ← 이 답이 오늘 전략을 결정한다

## 10:00 — Gate 1 판정 (이 표만 보고 결정)

| 완주 횟수 | 판정 | 행동 |
| :--- | :--- | :--- |
| **5/5** | 합격 | Clone → 최고 속도만 **+0.2** 올려 45분 재학습. 나머지는 건드리지 않는다 |
| **3~4/5** | 경계 | Clone → 최고 속도만 **−0.2** 내린다. 보상 함수는 그대로 |
| **0~2/5** | 불합격 | Clone → 최고 속도 **−0.4**. 두 번 연속 실패하면 그 레인은 접고 A 레시피로 |

**한 번에 한 가지만 바꾼다.** 1순위로 바꿀 것은 항상 속도다.

### 스윕 결과 읽는 법

B와 C는 각각 3개가 **최고 속도만 다르고 나머지는 완전히 동일**하다.
따라서 세 개를 나란히 놓으면 **완주율이 무너지는 속도가 곧 시뮬 상한**이다.

예: B가 2.2→5/5, 2.4→5/5, 2.6→2/5 라면 시뮬 상한은 2.4~2.5 사이.
그러면 2.5로 한 번 더 찔러본다.

### 레인별 해석

- **A가 5/5** → 보험 확보. export해서 팀원들이 import하면 각자 여기서 Phase 2 출발.
  **A가 5/5가 아니면 다른 무엇보다 A를 먼저 살린다.**
- **B가 잘 나옴** → 레이싱 라인이 통한다는 뜻. 가장 높은 상한선.
  B만 유독 낮으면 궤적 보상 계수 `-6.0`이 너무 강해 라인에 집착하다 이탈하는 경우 → `-4.0`으로 완화.
- **C가 잘 나옴** → 감가속 타이밍이 중요하다는 뜻. 헤어핀 이탈 시 `k = 4`를 5~6으로 올려 더 미리 감속.
- **D가 느리지만 안정적** → 정상이다. D의 가치는 랩타임이 아니라 실차 안정성.
  **랩타임이 느려도 삭제하지 않는다.**

## 13:00 — 오후 실차 테스트 (오늘의 최우선 산출물)

순위는 실물 트랙에서 갈린다. 오전이 늦어져도 **오후 실차 시간은 절대 놓치지 않는다.**

### 가져갈 것

- [ ] 모델 파일 — 각 모델 페이지 **Actions → Download physical car model**로 미리 내려둘 것
- [ ] **줄자** — 트랙 폭을 재서 re:Invent 2018(76cm)인지 A to Z Speedway(107cm)인지 확정
- [ ] **스톱워치**(휴대폰) — 탈선 실비용 측정
- [ ] 완충 배터리, 기록용 노트

### 측정할 3가지

| 항목 | 방법 | 왜 필요한가 |
| :--- | :--- | :--- |
| **① 탈선 실비용** | 일부러 한 번 이탈시켜 정지→리셋→속도 회복까지 스톱워치로 3회 측정 | 본선 공격 수위를 정하는 유일한 근거. 2초 안팎이면 공격이 유리, 4초 넘으면 보수적으로 |
| **② 워블 임계 속도** | 스로틀을 낮게 시작해 **0.2 m/s 단위로** 올리며 지그재그 시작점 기록 | 본선 스로틀 상한. 이 값보다 **한 단계 아래**로 달린다 |
| **③ 배율별 랩타임** | 스로틀 **80 / 90 / 100%**에서 랩타임과 탈선 횟수 | 본선 1·2차 배율을 여기서 그대로 고른다 |

### 실차 기록표

| 모델 | 배율 | 랩타임 | 탈선 횟수 | 최종 시간 (랩 + 탈선×실비용) |
| :--- | :--- | :--- | :--- | :--- |
| | 80% | | | |
| | 90% | | | |
| | 100% | | | |

**선발 기준은 랩타임이 아니라 최종 시간이다.** 페널티가 싸다면(리셋 중 시계 정지 + 1초)
조금 흔들려도 빠른 쪽이 이긴다. **탈선 1회를 포함한 기록도 후보로 인정한다.**

트랙 시간이 짧으면 투입 순서는 **빠른 쪽부터: C → B → D → A**.

## 19:00 — Gate 3: 본선 모델 2개 확정

1. **안전 모델**: 실차에서 탈선 0으로 완주한 것 중 가장 빠른 모델 + 보수적 배율 → 본선 1차용
2. **공격 모델**: 실차 최종 시간이 가장 짧은 모델 + 검증된 최고 배율 → 본선 2차용
3. 남은 학습 슬롯 전부를 **공격 모델의 미세 변형**(속도 캡 ±0.2)에 투입

> **절대 규칙: 실차 검증을 받지 않은 모델은 본선에 올리지 않는다.**
> Day 3 아침에는 검증할 시간이 없고, 미검증 모델을 올리는 것은 순위가 아니라
> 기록 자체를 거는 도박이다.
