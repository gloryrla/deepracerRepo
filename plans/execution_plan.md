## 1. 우선순위 — 이 순서를 지켜라

성적에 필요한 모델은 **정확히 2개**다. 그 2개를 확실히 확보하는 것이 최우선이고,
나머지는 그 다음이다.

| 순위 | 레인 | 캡 | 왜 이 순서인가 |
| :--- | :--- | :--- | :--- |
| **1** | **A** 중앙선 | 2.2 | **가장 빨리 수렴한다.** 보상이 단순해 45분이면 완주하는 모델이 나온다. 하루밖에 없을 때 "아무것도 없는 상태"를 가장 먼저 벗어나게 해주는 카드 |
| **2** | **E** 궤적 매칭 | 2.6 | **상한이 가장 높다.** 최적 경로와 그 지점의 목표 속도를 함께 주는 가장 정보량 많은 보상. 본선 주력 후보 |
| 3 | **B** 레이싱 라인 | 2.6 | E가 수렴하지 못할 때의 대안(위치만 매칭하므로 더 단순하다) |
| 4 | **C** 속도 프로파일 | 2.6 | 다른 메커니즘. 여력이 있을 때만 |
| 5 | **D** 워블 억제 | 2.2 | **오후 실차에서 워블이 관측된 뒤에** 만든다. 미리 만들 필요 없다 |

**A와 E를 먼저 걸어라.** 이 둘이 5/5 완주하면 최소한 본선에 낼 2개가 확보된다.
그 다음부터가 개선 작업이다.

## 3. 1라운드 결과 판정 (Gate 1)

각 모델의 **Evaluation 탭**에서 5회 평가 결과를 보고 아래 표대로만 움직인다.

| 5회 중 완주 | 판정 | 행동 |
| :--- | :--- | :--- |
| **5/5** | 합격 | Clone → **속도만 +0.2** 올려 재학습. 사다리를 올라간다 |
| **3~4/5** | 경계 | Clone → **속도만 −0.2**. 보상 함수는 건드리지 않는다 |
| **0~2/5** | 불합격 | Clone → **속도 −0.4**. 두 번 연속 실패하면 그 레인을 접고 A 레시피로 |

**한 번에 하나만 바꾼다.** 1순위로 바꿀 것은 항상 속도다.

### 레인별로 결과가 이러면

- **A가 5/5** → 본선 후보 1개 확보. 안심하고 나머지에 집중한다
- **A가 5/5 아님** → **다른 무엇보다 A를 먼저 살린다.** 캡을 2.0까지 내려도 된다.
  낼 모델이 없으면 전략 자체가 성립하지 않는다
- **E가 잘 나옴** → 주력이다. 사다리를 2.8까지 올려본다
- **E만 유독 낮음** → 위치와 속도를 동시에 요구해 제약이 과한 경우다.
  파일 상단의 `BETA`(속도 항 가중치)를 0.8 → 0.4로 낮춰 위치부터 학습하게 한다
- **B·C가 E보다 좋음** → 정보량 많은 보상이 항상 이기는 건 아니다. 좋은 쪽을 밀어라

## 4. 오후 — 실차 테스트가 진짜 선발전

**오전 학습이 늦어져도 실차 시간은 절대 놓치지 마라.** 순위는 실물 트랙에서 갈린다.

### 가져갈 것

- [ ] 모델 파일 — `Actions → Download physical car model`로 **미리** 내려둘 것
- [ ] 스톱워치(휴대폰), 줄자, 완충 배터리, 기록용 노트

### 측정 3종 — 이게 오늘의 진짜 산출물

| 항목 | 방법 | 왜 |
| :--- | :--- | :--- |
| **① 탈선 실비용** | 일부러 이탈시켜 정지 → 재배치 → 속도 회복까지 3회 계측 | 본선 공격 수위를 정하는 유일한 근거. 우리 추정은 1.8초 |
| **② 워블 임계 속도** | 스로틀을 0.2 m/s 단위로 올리며 지그재그 시작점 기록 | 본선은 그보다 **한 단계 아래**로 |
| **③ 배율별 랩타임** | 스로틀 80 / 90 / 100%에서 랩타임과 탈선 횟수 | 본선 배율을 여기서 고른다 |

트랙 시간이 짧으면 투입 순서는 빠른 쪽부터 **E → B → C → A**.
**워블이 관측되면 그때 레인 D를 만들어 밤에 학습시킨다.**

### 기록표

| 모델 | 배율 | 랩타임 | 탈선 | 최종 시간 (랩 + 탈선×실비용) |
| :--- | :--- | :--- | :--- | :--- |
| | 80% | | | |
| | 90% | | | |
| | 100% | | | |

## 5. 밤 — 본선 모델 2개 확정 (Gate 3)

**선발 기준은 랩타임이 아니라 최종 시간이다.** 평균 채점이므로 두 모델 모두 좋아야 한다.

1. 실차 기록을 `랩타임 + 탈선횟수 × 실비용`으로 줄 세운다
2. **기대 시간이 가장 낮은 2개**를 고른다. 편차가 큰 모델은 같은 평균이라도 탈락
3. 남은 슬롯 전부를 상위 모델의 **속도 캡 ±0.2 변형**에 투입

> **절대 규칙: 실차 검증을 받지 않은 모델은 본선에 올리지 않는다.**
> 내일 아침엔 검증할 시간이 없고, 미검증 모델을 올리는 것은 순위가 아니라
> **기록 자체를 거는 도박**이다.

## 7. 최악의 경우 대비

**오늘 아무것도 5/5를 못 넘기면** — 캡을 2.0, 필요하면 1.8까지 내리고 레인 A 하나만
집중한다. **느려도 완주하는 모델 2개**가 미완주 1개보다 무조건 낫다.
평균 채점에서 DNF는 성적을 파괴한다.

**큐가 다시 막히면** — 안 쓰는 모델을 즉시 삭제해 앞자리를 비우고, 그래도 안 되면
운영진에게 동시 학습 가능 개수를 확인한다. 1개씩만 돈다면 우선순위 1·2번만 돌린다.
