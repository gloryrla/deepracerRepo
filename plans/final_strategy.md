## 2. 핵심 통찰 — 지금 개선할 것은 "빠른 모델"이 아니라 "느린 모델"이다

채점이 두 모델의 **평균**이므로, 조합 기대값은 이렇게 된다.

| 조합 | 평균 |
| :--- | ---: |
| E-v1 + C-v1 | 8.378 |
| E-v1 + A-v1 | 8.487 |
| E-v1 + D-v1 | 8.585 |
| **E-v1 + E-v1급 모델** | **7.473** |

**E-v1을 2.8로 올려 0.2~0.4초 깎는 것보다, 두 번째 모델을 E급으로 만드는 것이
0.9초를 깎는다.** 성적을 끌어내리는 것은 느린 쪽이다. 여기에 자원을 넣는다.

게다가 E-v1의 편차는 **0.086초**다. 이건 정책이 매우 안정적으로 수렴했다는
신호이고 평균 채점에서 가장 값진 자산이다. 캡을 올려 이걸 흔드는 것은
0/5라는 표본으로 정당화되지 않는다. 탈선 0/5는 탈선 확률이 0.22 이하라는 증거가
아니다 — 95% 상한은 약 0.45다. 캡 2.8의 손익분기가 0.22회이므로 **캡 인상은
기대값이 플러스라고 말할 수 없다.**

얻는다. 허용되지 않으면 3번으로 간다.

## 4. 방향이 반시계로 확정되면

**시계 모델 4개가 전부 무효가 된다.** 현재 반시계 자산은 E-CCW-U1-V220
하나뿐이고 11.347초 · 탈선 9회다.

즉시 할 일:
1. **E-CCW-U1-V220 Clone → 60분** (LR 0.0001, Entropy 0.005). E-v1이 60분에서
   7.47초를 냈고 E-CCW는 45분밖에 못 돌았다. 15분 부족이 유력한 원인이다
2. 여력이 있으면 C 레시피로 반시계 모델 하나 더. C-v1은 탈선 0회로 가장
   일관적이었다
3. 시계 모델은 건드리지 않고 남겨둔다. 방향 정보가 또 바뀔 수 있다

## 5. 절대 잊지 말 것

**모든 숫자가 시뮬레이터 기록이다.** 알려진 실차 우승 페이스는 10~11초대이고,
시뮬 7.47초는 실차 7.47초가 아니다. 서보 지연, 타이어 슬립, 배터리 전압 강하가
빠져 있다.

시뮬 기록은 **절대값이 아니라 상대 순위와 편차**로만 쓴다.
**실차 검증을 받지 않은 모델은 본선에 올리지 않는다.**
