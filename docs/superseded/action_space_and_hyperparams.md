## 1. Action Space (이산 공간: Discrete Space 권장)

Physical AI 실차 대회에서는 불필요하게 촘촘한 Action Space(예: 20~30개)를 설정하면 탐색 공간이 지나치게 커져 2박 3일 내에 수렴하지 못합니다. **9~15개 내외의 이산 공간(Discrete Action Space)**이 가장 빠른 수렴과 안정적인 제어를 보여줍니다.

### 추천 1: 균형형 Action Space (10~12 Actions)

| Action 번호 | Steering Angle (도) | Speed (m/s) | 설명 |
| :--- | :--- | :--- | :--- |
| 0 | -25.0° | 1.3 m/s | 급격한 좌회전 코너 |
| 1 | -15.0° | 1.8 m/s | 완만한 좌회전 |
| 2 | -5.0° | 2.2 m/s | 미세 좌측 보정 |
| 3 | 0.0° | 2.4 m/s | 직선 주로 최대 가속 |
| 4 | 5.0° | 2.2 m/s | 미세 우측 보정 |
| 5 | 15.0° | 1.8 m/s | 완만한 우회전 |
| 6 | 25.0° | 1.3 m/s | 급격한 우회전 코너 |
| 7 | 0.0° | 1.5 m/s | 안전 직진 속도 |

> **핵심 원칙**: 
> * 큰 각도(20° 이상)는 반드시 **낮은 속도(1.2~1.4 m/s)**와 매핑할 것.
> * 최고 속도(2.2~2.4 m/s)는 **직선/미세 각도(0~5°)**에서만 허용할 것.

## 2. PPO 하이퍼파라미터 튜닝 가이드

| 하이퍼파라미터 | 기본값 | 우승자 추천값 | 상세 튜닝 가이드 |
| :--- | :--- | :--- | :--- |
| **Gradient descent batch size** | 64 | **64** | 데이터 수집 대비 안정적인 그래디언트 업데이트 |
| **Number of epochs** | 10 | **3 ~ 5** | 에폭이 너무 높으면 정책이 과적합되어 새로운 코너에서 튕김 |
| **Learning rate** | 0.0003 | **0.0003 ~ 0.0001** | Phase 1은 0.0003, Phase 2/3 복제 학습 시 0.0001로 감소 |
| **Entropy** | 0.01 | **0.005 ~ 0.01** | Phase 1 탐색은 0.01, Phase 2/3 정밀 제어는 0.005 |
| **Discount factor ($\gamma$)** | 0.999 | **0.99 ~ 0.995** | 단기 코너 대응력 향상을 위해 0.995 전후 추천 |
| **Loss type** | Mean Squared Error | **Huber** | 이상치(Outlier)에 덜 민감하여 학습 안정성 향상 |
| **Number of experience episodes** | 20 | **20** | 표준 에피소드 수 유지 |

## 3. 학습 시간(Training Time) 배분 전략

* **1차 기본 모델 (Phase 1)**: 45분 ~ 60분 (완주율 100% 달성 시 즉시 중단)
* **2차 복제 모델 (Phase 2)**: 60분 (궤적 피팅)
* **3차 복제 모델 (Phase 3)**: 30분 ~ 45분 (최고 속도 캡 & 스무딩)
* **주의**: 하나의 모델을 3시간 이상 장시간 연속 학습시키면 시뮬레이션 특정 픽셀에 과적합되어 **실제 트랙에서 직진만 하거나 급발진 탈선**이 발생합니다. 반드시 45~60분 단위의 **Clone Learning**을 수행하세요.
