# 실차 튜닝 기록

> 모델을 바꾸지 않고 **스로틀 배율만** 조절해 이탈하지 않는 최대선을 찾은 과정.
> 최종 모델: `D-speedup-clone` (`/models/r58VqnOQYgCIgy7`)

---

## 왜 스로틀 스윕이 핵심 작업이 되었나

학습 1회에 **약 2시간 30분**이 든다(훈련 1시간 + 검증·실행 1시간 + 기타).
반면 **스로틀 배율 변경은 즉시 반영되고 1회 주행은 수십 초**다.

| 조절 수단 | 1회 반복 비용 |
| :--- | :--- |
| 재학습 · 파인튜닝 | 약 2시간 30분 |
| **스로틀 배율** | **수십 초** |

그래서 모델을 고정한 뒤 **2% 단위로 배율을 올려가며 이탈 경계선을 찾는 것**이
남은 시간에 성적을 올리는 가장 효율적인 방법이었다. 학습이 병목인 환경에서는
**학습 밖에서 돌릴 수 있는 손잡이를 찾는 것**이 전략의 일부가 된다.

## 1차 장소

| 배율 | 결과 |
| :--- | :--- |
| 70% | 정상 완주 |
| 72% | 이탈 |
| 74% | 이탈 |
| 75% | 이탈 |

경계선이 **70~72% 사이**로 좁혀졌다.

---

## 장소 이동 후 — 배율 척도가 달라졌다

**"저기 75가 여기 65"** — 같은 배율 숫자가 다른 매트에서 다른 속도를 냈다.
노면 마찰과 배터리 상태가 달라지면 배율-속도 관계가 이동한다.

**이전 장소의 측정값을 그대로 가져올 수 없다는 뜻이다. 스윕을 처음부터
다시 했다.**

| 배율 | 결과 |
| :--- | :--- |
| 60% | 완전 주행 |
| 61% | 안전 |
| 62% | 이탈은 없으나 **살짝 걸침 — 위험** |
| 63% | 코너 안정권 (speed clone 모델) |
| 64% | **이탈 1회 발생** |

**코너 안정 상한 = 62~63%.**

---

## 최종 주행 전략 — 구간별 수동 배율 제어

배율을 하나로 고정하지 않는다. **랩 전체에서 가장 느린 구간이 상한을 결정하는
문제**를 구간을 나눠 푼다.

```
출발 75%  ->  코너 진입 전 62%로 낮춤  ->  코너 통과  ->  즉시 75%로 복귀
```

| 구간 | 배율 | 근거 |
| :--- | :--- | :--- |
| 직선 | **75%** (이후 85%까지 시도) | 조향이 없으니 접지 여유가 있다 |
| 코너 | **62%** | 20도 조향의 물리 한계 |

**출발 위치도 튜닝 대상이었다.** 카메라 기준 가장 뒤에서 출발해 가속 거리를
확보했다.

---

## ±20도가 조향 상한인 이유 (실측)

코너에서 날아가는 것을 막으려고 25도, 30도까지 올려 시도했다.
**"더 큰 조향이 더 나은 코너링"이라는 추측은 실차에서 틀렸다.**

| 증상 | 해석 |
| :--- | :--- |
| 바퀴가 헛돌았다 | 접지 한계 초과. 조향을 더 넣는 것이 해결이 아니다 |
| 직진에서 좌우로 왔다갔다 | 큰 조향 액션이 존재하는 것만으로 정책이 그것을 쓴다. 잃는 시간이 코너에서 얻는 것보다 컸다 |

물리로 계산해도 같은 결론이 나온다 (축간거리 0.165 m, 0.6g 가정).

| 조향각 | 회전반경 | 한계속도 |
| ---: | ---: | ---: |
| 8도 | 1.174 m | 2.63 m/s |
| 14도 | 0.662 m | 1.97 m/s |
| **20도** | **0.453 m** | **1.63 m/s** |
| 30도 | 0.286 m | 1.30 m/s |

**30도는 1.30 m/s를 넘으면 어떻게 꺾어도 밀려나간다.** 조향각을 키우는 것은
코너 속도를 올려주지 않는다. 오히려 상한을 낮춘다.

**결론: 20도로 제한하고, 그 각도에서는 속도를 낮추고(1.30) 직진에서 올린다(2.60).**
최종 액션 스페이스가 그 결론이다.

## 학습으로 되돌아갔을 때 실패한 것들

최종 모델 이후 더 개선하려고 시도했으나 **오히려 나빠진** 것들.

| 시도 | 결과 |
| :--- | :--- |
| 조향각 추가 확장 | 위 이유로 악화 |
| 액션 속도 재조정 | 개선 없음 |
| 좌표 추가 학습 | 악화 (레이턴시 문제 재발) |

**한 번 실차에서 검증된 모델을 이기는 것이 생각보다 어렵다.**
남은 시간이 적을 때는 검증된 모델을 지키고 **모델 밖의 손잡이(배율, 출발 위치,
구간 제어)를 돌리는 것**이 기대값이 높았다.
